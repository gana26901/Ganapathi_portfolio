Network Automation & Monitoring

Cisco device configuration automated with Python and Netmiko inside an EVE-NG lab, paired with Zabbix monitoring over SNMP for dashboards and alerting.

Dashboard — Zabbix SNMP monitoring (illustrative)

Key points

  • Lab-first workflow — built and tested in EVE-NG before touching production hardware.
  • Python + Netmiko — pushes baseline configuration to multiple devices from a single script.
  • Zabbix monitoring — SNMP-based discovery, dashboards, and threshold alerting for every device.
  • Per-device reporting — script reports success/failure per device instead of failing silently.

Configuration code

lab_automation.py
from netmiko import ConnectHandler

lab_devices = [
    {"device_type": "cisco_ios", "host": "192.168.100.11", "username": "admin", "password": "********"},
    {"device_type": "cisco_ios", "host": "192.168.100.12", "username": "admin", "password": "********"},
]

# Baseline config: enable SNMP polling + central logging for Zabbix
base_config = [
    "snmp-server community public RO",
    "snmp-server location EVE-NG-LAB",
    "logging host 192.168.100.5",
]

def push_config(device):
    with ConnectHandler(**device) as conn:
        conn.send_config_set(base_config)
        conn.save_config()
        print(f"Configured {device['host']} — SNMP + logging enabled")

def run_lab_automation():
    ok = 0
    for device in lab_devices:
        try:
            push_config(device)
            ok += 1
        except Exception as err:
            print(f"Failed: {device['host']} — {err}")
    print(f"{ok}/{len(lab_devices)} EVE-NG lab devices configured")

if __name__ == "__main__":
    run_lab_automation()

Multi-Branch Routing & VPN Lab

A multi-site OSPF network connecting branch offices over a GRE tunnel wrapped in IPsec — with routing convergence and failover tested and documented.

Proof of work

Terminal — VPN tunnel status (illustrative)

Verification — OSPF convergence & failover (illustrative)

Key points

  • Multi-site OSPF — branch routers exchange routes with HQ over a single area.
  • GRE over IPsec — GRE carries the routing protocol, IPsec encrypts everything inside it.
  • Failover tested — measured convergence time when a link or tunnel drops.
  • Documented — full topology diagram and IP addressing scheme delivered alongside the lab.

Configuration code

branch-router.cfg
! Branch router — GRE over IPsec to HQ
crypto isakmp policy 10
 encryption aes 256
 authentication pre-share
 group 14
crypto isakmp key ******** address 203.0.113.1
!
crypto ipsec transform-set TS esp-aes 256 esp-sha-hmac
crypto map VPN-MAP 10 ipsec-isakmp
 set peer 203.0.113.1
 set transform-set TS
 match address VPN-TRAFFIC
!
interface Tunnel0

!
